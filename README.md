
# Controle de Níveis de Água

Projeto desenvolvido para a Agenda 11 de Desenvolvimento de Sistemas I.

## Objetivo
Simular o monitoramento de um reservatório de água, exibindo mensagens coloridas de acordo com o nível.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama

## Instalação
Execute o comando:

pip install -r requirements.txt

## Execução
Execute:

python Igor_Ag11_DSI.py

## Níveis do reservatório
1. Muito baixo (crítico) - vermelho
2. Baixo - amarelo
3. Médio - verde
4. Alto - ciano
5. Muito alto (alerta) - azul
